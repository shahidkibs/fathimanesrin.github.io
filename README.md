# Fathima Nesrin — Portfolio

Blue portfolio with operations and engineering experience, a downloadable CV and four videos hosted with the site.

## Publishing

In Settings → Pages, choose **Deploy from a branch**, **main**, **/ (root)**, and save.

Site address: https://shahidkibs.github.io/fathimanesrin.github.io/

The website is buildless. Edit `index.html`, `styles.css` and `app.js` directly. Video files and their preview images are in `assets/videos/`.
